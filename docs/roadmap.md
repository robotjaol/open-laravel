# Roadmap and known limitations

Honest list of what is **not** in this template. See also [implementation status](reports/implementation-status.md).

Not implemented: two-factor authentication / passkeys, social login, teams/multi-tenancy, file uploads, i18n string catalogue (locale setting exists; UI strings are English), websockets, full-text search, PDF/CSV export, session revocation UI (sessions are listed, not revoked), email templates beyond framework defaults.

Candidates for next versions: 2FA (Laravel Fortify or passkeys), session revocation, CSV export on tables, translation layer, Playwright accessibility scans with axe-core, OpenAPI generated from code.
